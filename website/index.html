AI Brief — 7 August 2026

5 things worth knowing from the past three weeks. Reddit could not be reliably evaluated because approved API credentials are not yet available.

Important

Claude Opus 5 is a substantial agentic-coding upgrade

Official. Released July 24, Opus 5 targets complex agentic coding and long-horizon work with a 1M-token context window, up to 128k output tokens, and thinking enabled by default at the same $5/$25 per-million-token price as Opus 4.8. It adds mid-conversation tool changes, a lower 512-token prompt-cache minimum, and stronger multi-agent coordination. Migration is not completely frictionless: disabling thinking at xhigh or max returns a 400 error. What’s new in Claude Opus 5

Codex CLI 0.147.0 makes plugins and long-running work more portable

Official. The August 7 release adds portable Agent Plugins with multi-catalog search, persistent manually ordered conversation sections, --approve-for-me for automatically reviewed approvals, Cursor skill imports, and opt-in MCP 2026-07-28 support. It also hardens plugin isolation, local-project trust, secret redaction, and Windows process handling. The deprecated codex exec --full-auto flag is removed; use --sandbox workspace-write. Codex changelog

Claude Code 2.1.224 expands agents beyond one session or machine

Official. The August 7 release adds Team and Enterprise self-hosted runners, cross-session SendMessage, and ListAgents discovery across machines on macOS and Linux. It removes the 200-subagent-per-session spawn cap while retaining concurrency and nesting limits, and adds safer credential masking and approval handling. The practical shift is toward durable, distributed agent teams rather than isolated terminal sessions. Claude Code 2.1.224

Worth knowing

GPT-5.6 changed in quality, price, and recommended defaults

Official. OpenAI says GPT-5.6 Sol became more accurate and consistent on August 6, but published no supporting benchmarks, so the size of the improvement remains unquantified. Separately, Terra became 20% cheaper and Luna 80% cheaper; Sol now powers eligible hosted Codex code review and QA, and ChatGPT-authenticated Codex users must move from GPT-5.4/5.4 mini to Terra/Luna before their August 31 retirement. Sol update · OpenAI weekly digest

Codex desktop gained a more unified research-and-review workflow

Official. Over July 20–31, local projects gained multiple folders with a designated primary folder, combined diff review across repositories, browser-history and Google search in the built-in browser, richer Chrome-extension context, and an Activity view for work needing attention. Together these changes reduce context switching for multi-repository implementation and web-backed research. OpenAI weekly digest
